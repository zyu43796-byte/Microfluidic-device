双击本目录 **启动适配版.cmd**，或运行 `dist/DMF_Host_Adapted/DMF_Host_Adapted.exe`。移动到其它电脑时须复制完整的 `dist/DMF_Host_Adapted` 文件夹。

## AC 操作

1. 关闭占用同一COM口的串口助手，打开上位机并连接串口（115200、8N1）。连接初始化会停止输出，不自动开启AC。
2. 核对压实、位置联锁和电极编号方向，勾选编号核对。若需摄像头，在开启AC前打开。
3. 设置电压（40～150V，默认80V），频率1000Hz、AC/POL延时40μs。
4. 点击 **开启 AC 模式**。检查联锁、应用参数、下发全零帧后等待选择电极，此时无AC波形。
5. 右键电极后持续驱动，方向按钮按空间邻接移动。每次切换先关闭AC，检查联锁并更新数据，再开启AC。界面选择和回执不能证明液滴移动或实际电压正确。
6. **取消全部电极**：关闭波形并清空选择，保留模式，可继续选择。**关闭 AC**：退出模式并停止输出，之后需重新开启。红色 **停止全部输出（Esc）** 随时可用。

去掉授权按钮、倒计时和60秒总运行限制。自动流程可以超过60秒，正常结束仍停止全部输出。更改电压或取消编号核对会停止，需手动重新开启。

实现方式：只更新上位机，不烧录固件。运行期间约每20秒（自动流程在帧间）检查联锁与固件状态并续接已有60秒通信期限，后台不刷屏。通信正常时持续运行；固件已停止、联锁异常、通信超时或上位机暂停超过期限时不自动重启。固件仍保留通信中断后的超时停止，这不是即时急停。

## 右下角灯光面板

连接后可独立使用，**无需开启AC**。控制30颗灯珠。

1. 选择颜色或灯效。上方色块只选择颜色，不立即发送。
2. 调整亮度 **0～255**（默认80，0为熄灭），动画帧间隔 **10～1000ms**（默认30，越小越快）。
3. 点击 **应用灯光**，匹配回执后显示“灯光指令已确认”；修改设置后需再次点击应用。
4. **关闭灯带**：取消动画并整条熄灭，不关闭AC。

| 模式 | 作用 |
|---|---|
| 白、红、绿、蓝、黄、青、紫红 | 静态常亮 |
| 彩虹流动 | 彩虹连续流动 |
| 流星拖尾 | 流星及变色拖尾，可将亮度调到112 |
| 多点追逐 | 多色光头追逐 |
| 逐颗累加 | 逐颗填满后渐灭重来 |
| 星空闪烁 | 彩色星点闪烁 |
| 霓虹对撞 | 两端彗星相撞、彩虹扩散 |
| 六种轮播 | 每种10秒，统一使用界面亮度 |

灯光协议对应桌面 `Drop_Drive_16Byte_ZCY_success` 的 `pwm_fx_v4_core` 六灯效版。旧固件不支持灯效时会报错，不假显示成功。

当前六灯效固件的 `all_stop` 会关灯，因此关闭AC、红色停止、流程完成、断开串口都会同时关闭灯带。连接后可重新单独开灯。

## 右下角磁杆页（2026-10-15）

右下角现在分为“灯光 / 磁杆”两个标签。温度曲线、加热和 PID 按要求暂不增加；2/3/4 号板固件均未修改，无需为这次界面升级重新烧录。须使用已恢复磁杆联锁的固件。

连接串口并确认压实、位置联锁正常后，切换到“磁杆”：

| 操作 | 效果 |
|---|---|
| 动作保持 · ON | 检查联锁并发送 magnet on，保持动作极性，无需开启 AC |
| 返回默认 · OFF | 发送 magnet off，切回默认极性；该降风险指令不要求联锁闭合 |
| 定时动作 | 设置 100–5000ms（默认500ms），发送ON后由上位机计时，再发送OFF |
| 停止全部输出 / Esc | 取消进行中的操作并发送 all_stop，同时关闭AC、灯带，磁杆恢复默认极性 |

**OFF 不等于断电或机械停止。** 两线推杆的伸缩方向取决于接线。界面只显示固件指令回读，没有行程/到位传感器反馈。

单独使用磁杆时，返回默认或定时完成后会用 all_stop 解除授权，因此灯带也会关闭；AC 模式开启期间，返回默认只影响磁杆，不关闭AC。定时动作期间可随时按红色全停按钮，但普通操作等待当前任务结束。

磁杆保持时约每秒检查联锁与固件授权，每20秒续期既有60秒固件期限，后台日志不刷屏。固件已停机不会自动重启。断开串口/关闭窗口先请求全停；通信中断时无法保证立即返回，固件授权超时是后备措施（最长约60秒），不能作为硬件急停。若状态未确认，人工切断相关供电；切回默认极性可能导致反向运动。

定时是上位机近似计时，含串口和系统调度误差，不用于精密脉宽。需要相机时先打开，再启动磁杆或AC。首次使用请空载确认方向与默认状态，避免机构夹伤。

## 其它操作与限制

- Ctrl+右键多选，松开Ctrl统一发送；Shift+左键固定/取消固定电极。
- 自动流程使用电极列表、保持秒数、相机预览；每帧0.001～10秒，空列表 `[]` 为全关等待。流程结束停止全部输出。
- 相机提前打开；未实现录像、加热、荧光、液滴检测仍未适配。
- 停止或关闭串口发送 `all_stop`，不物理切断4号板升压供电。停止未确认时须手动切断高压。连续AC需继续观察已知U7温升问题。
- 本次未改变SPI速率、位图、电极映射或下位机，不代表已解决异常电极问题。
